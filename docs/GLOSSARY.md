# GLOSSARY.md — Glossário de Termos do Start Metric

| Termo | Definição | Contexto | Termos Relacionados |
|---|---|---|---|
| **ROAS Real** | Retorno sobre o Gasto em Anúncios calculado dividindo a **receita real atribuída** pelo gasto registrado na Meta. | Métricas Core | ROI, Spend, CPA |
| **Lucro Líquido por Campanha** | Receita real atribuída à campanha subtraída do gasto em anúncios, taxas de cartão/gateway e estornos. | Financeiro | Lucro Bruto, Margem |
| **CPA (Custo por Aquisição)** | Gasto total da campanha dividido pelo número de conversões ou vendas atribuídas. | Performance | CPC, CTR, CPL |
| **Garimpo** | Módulo de inteligência competitiva e esteira de ofertas validadas de mercado com copy, criativo e análise de longevidade. | Esteira de Ofertas | Spy, Criativos, Ângulos |
| **Meta CAPI** | Conversions API da Meta para envio de eventos de compra e lead diretamente do servidor para o Pixel com deduplicação. | Rastreamento & Atribuição | Pixel, event_id, SHA-256 |
| **Evolution API** | Engine e API para integração multi-instância de WhatsApp usada para envio automatizado de relatórios matinais. | Mensageria | WhatsApp, QR Code, Proxy |
| **Multi-Tenancy** | Modelo arquitetural onde cada cliente ou agência possui seus dados isolados logicamente por `organization_id` via RLS. | Banco & Segurança | Supabase, RLS, Org |
| **PAINEL_SENHA** | Mecanismo de autenticação simplificado por senha master que gera um cookie de sessão seguro (`painel_session`). | Autenticação | Middleware, Sessão, Auth |
